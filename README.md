# Piyush More — Portfolio

Static HTML/CSS/JavaScript portfolio prepared for https://piyush8227.github.io/.

## Publish

Create the public repository `piyush8227.github.io` under `piyush8227`, initializing it with a README. Upload these files to its root. Enable Settings → Pages → Deploy from a branch → main → /(root). Commit changes to main to publish future updates.

## Run locally

From this folder, run `python -m http.server 8000 --bind 127.0.0.1`, then open http://localhost:8000. On macOS/Linux use python3 if needed.

## Edit

- index.html: profile content, projects, links and metadata.
- styles.css: theme, responsive layouts and CSS effects.
- app.js: scroll rotation, photo glitter, motion controls.
- assets/: portrait and gold sculpture.
- files/: résumé PDF.

No build step, backend or API keys are required. Includes the portrait visibility correction and View résumé link. GitHub Pages has not yet been enabled.
