  • AutoGen

View source on GitHub ↗
How I built AutoCodeGPT
Problem
Turn a coding request into Python that can be executed and revised, rather than stopping at generated text.
My approach
Separate reasoning from execution: an AutoGen agent proposes a solution, a Docker-based execution agent runs it, and feedback drives revisions.
Engineering decision
A separate container isolates the code runtime from the reasoning agent. This is a containment choice, not a guarantee that generated code is safe.
Validation & limits
Execution feedback can expose runtime failures. A successful run alone does not prove algorithmic correctness; task-specific tests are still necessary.

How I built AutoBlogGPT
Problem
Generate a structured blog grounded in retrieved context, with a review step before the final output.
My approach
Use LangGraph to coordinate retrieval, generation, evaluation, and formatting. Shared state carries context and feedback between stages.
Engineering decision
An explicit workflow makes review and revision part of generation. LangChain supports retrieval and LLM integration.
Validation & limits
Representative prompts and evaluator feedback guide refinement. Automated review remains model-dependent and does not guarantee factual accuracy.
Delivery
Deployed on Hugging Face Spaces using GitHub Actions-based CI/CD, as documented in my résumé.
ML DATASET ENGINEERING03

SnP Image Labeler

A desktop annotation and dataset validation tool built for real ML workflows. Structured ground truth helps the team benchmark 10+ feature pipelines.

  • Python
  • PyQt5
  • Computer Vision
View source on GitHub ↗
How I built SnP Image Labeler
Problem
The team needed structured ground truth to compare Smart Vision Glasses inference results with expected outputs.
My approach
Built a Python and PyQt5 desktop application with configurable telemetry fields, bounding boxes, OCR-assisted annotation, and JSON/CSV exports.
Engineering decision
Crash-safe writes protect annotation work; a 128 MB image cache supports browsing. Configurable fields let non-technical users adapt labels to different feature pipelines.
Validation & impact
Enabled systematic pass/fail validation across 10+ ML feature pipelines. Exported labels support benchmarking; the tool itself does not guarantee label quality.
Delivery
Packaged as a standalone Windows executable for internal annotation teams.
